# tteitti21-npc-behavior-experiment
Hobby project.<br>
Experimenting on how to develop npc behavior in relation to the user. <br>
1. Npc will notice the user when at set proximity and start moving towards the user. <br>
2. Npc will return to its original task when the user continuosly disengages the npc.<br>
3. Npc will have separate dialogues for each of the above situations. <br>
4. Npc will not notice the user if approaching from behind, until at close range.
